Recommended: sprout/src/task.rs — ManagedTask boot handshake

Current state:
  ManagedTask carries four PortHandles per supervised service
  (drv_req_write, drv_resp_read, boot_req_read, boot_resp_write) plus an
  optional resp_fd (bridged port FD).  The supervisor polls resp_fd with
  vfs_poll to detect driver readiness.

Migration path:
  Replace the four-port handshake with inbox messages:
  1. Driver sends a typed "Ready" inbox message (KindId::DRIVER_READY) to
     sprout's PID when it has finished initialising.
  2. Sprout waits on its own inbox FD (msg_inbox_open_self) combined with
     the existing devices_watch_fd in a single vfs_poll / WaitSet call.
  3. Facet registration (mount paths, service names) travels as additional
     inbox message fields — no separate port required.
  4. ManagedTask drops all four PortHandles; resp_fd is replaced by the
     shared inbox FD already open for the supervisor.

Why this target first:
  - Self-contained change: only sprout + cambium are affected.
  - Exercises the "Sprout supervises services as actors" rule from the spec.
  - No kernel changes needed; all primitives (msg_send, msg_inbox_open_self,
    vfs_poll) are already in place.
  - Removes the largest concentration of legacy port-handle wiring in userspace.
